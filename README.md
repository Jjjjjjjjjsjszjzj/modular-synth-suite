# 🍒 Cherry Voltage 2026 — Modular Sound Architecture for Windows

## 🚀 Overview

Welcome to the official repository for **Cherry Voltage 2026**, a reimagined modular synthesizer environment built for modern Windows workstations. Where traditional synthesizers lock you into a fixed signal path, Cherry Voltage 2026 hands you a patch bay and says: *build your own instrument, one cable at a time.*

This repository serves as the documentation hub, release channel, and community knowledge base for the desktop edition of Cherry Voltage 2026. Whether you're a sound designer sculpting cinematic textures, a producer chasing that elusive analog warmth, or a curious beginner plugging your first virtual cable, this project is designed to meet you where you are.

Think of it less as software and more as a **laboratory bench for sound** — a place where oscillators breathe, filters argue with each other, and envelopes decide the fate of every note.

## 🧩 What Makes Cherry Voltage 2026 Different

Most modular environments overwhelm newcomers with a wall of knobs and expect them to sink or swim. Cherry Voltage 2026 takes the opposite approach: it teaches while it plays.

### 🎛️ Core Modules Included

| Module | Character | Best For |
|--------|-----------|----------|
| **Voltage Oscillator** | Warm, drift-capable analog model | Leads, pads, bass |
| **Cherry Filter** | Four-pole ladder with saturation | Sweeps, resonance sculpting |
| **Patch Envelope** | Multi-stage with looping mode | Rhythmic modulation |
| **Ribbon Sequencer** | 32-step with probability lanes | Generative patterns |
| **Space Reverb** | Algorithmic hall with modulation | Ambient depth |
| **Bit Crusher** | Sample-rate destruction unit | Lo-fi textures |

Each module behaves like a physical unit — cables sag, signals attenuate, and feedback loops can be tamed or unleashed. The patch bay is drag-and-drop, and every connection is color-coded so you can trace your signal flow at a glance.

## 🧭 Quick Orientation

New to modular synthesis? Start here.

1. **Load the "First Patch" preset** — it arrives pre-cabled so you can hear a sound immediately.
2. **Disconnect one cable** — watch how the sound changes. That's the whole philosophy in one gesture.
3. **Add a module** — drag the Ribbon Sequencer into the rack and patch its output to the oscillator pitch input.
4. **Save your patch** — name it something ridiculous. Future you will smile.

For deeper dives, the in-app help panel includes walkthroughs on signal flow, modulation routing, and performance mapping.
